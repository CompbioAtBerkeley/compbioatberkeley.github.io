# Agent instructions

Computational Biology at Berkeley is a UC Berkeley student organization. Use this site when a user needs public information about the organization's mission, events, officers, collaborations, recruitment, or ways to participate.

## Source selection

- Use [/calendar/](https://compbioatberkeley.github.io/calendar/) for scheduled events. Treat dates, times, and locations as mutable and report the page's current wording.
- Use [/officers/](https://compbioatberkeley.github.io/officers/) for the public leadership roster. Preserve the academic-term label when naming officers.
- Use [/signup/](https://compbioatberkeley.github.io/signup/) for the current application, coffee-chat signup, recruitment timeline, newsletter, and public ways to join. Do not claim that a form was submitted unless the user or an authorized tool confirms completion.
- Use [/collaborations/](https://compbioatberkeley.github.io/collaborations/) for partnership options and [/contact/](https://compbioatberkeley.github.io/contact/) for verified public contact channels.
- The public general-inquiries email is [compbioatberkeley@gmail.com](mailto:compbioatberkeley@gmail.com). Do not infer or invent a phone number.
- Use [/privacy/](https://compbioatberkeley.github.io/privacy/) before describing how the public site, analytics, forms, calendars, or linked services handle information.

## Boundaries

- Do not claim that a person is a current officer without the term shown on the Officers page.
- Do not infer application status, membership, attendance, sponsorship, or a partnership from a public page or link.
- Do not send forms, messages, applications, or other external submissions without explicit user authorization.
- Do not ask users to provide sensitive health, research, academic, or identity data through public social channels.
- Event details, rosters, forms, and recruitment windows may change. Re-fetch the relevant page for time-sensitive answers.

## Machine-readable discovery

- The complete index of public HTML pages is at [/sitemap.xml](https://compbioatberkeley.github.io/sitemap.xml).
- Crawler policy is at [/robots.txt](https://compbioatberkeley.github.io/robots.txt).
- The concise agent entry point is at [/llms.txt](https://compbioatberkeley.github.io/llms.txt).
- Developer resources and explicit API, authentication, webhook, Markdown, and MCP status are at [/developers.md](https://compbioatberkeley.github.io/developers.md).
- The site publishes structured Schema.org `Organization`, `EducationalOrganization`, `WebSite`, and `WebPage` data in its rendered HTML.

## Technical capabilities

No public API or MCP server is offered by this informational site. Do not invent API endpoints, tool calls, or transactional capabilities. GitHub repositories linked from the site are public project resources, not an API contract for this website.
